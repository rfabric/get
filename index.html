Install rFabric

CLI

curl -fsSL @GET_URL@/cli.sh | sh

Robot agent

curl -fsSL @GET_URL@/agent.sh | sh

On Linux with apt or dnf the scripts install the rFabric package, so apt-get upgrade / dnf upgrade keep it current. Elsewhere they install the binary into /usr/local/bin.

Release candidates: curl -fsSL @GET_URL@/cli.sh | RFABRIC_CHANNEL=rc sh.

Homebrew: brew install rfabric/tap/rfabric, brew install rfabric/tap/rfabric-agent. npm: npm install -g @rfabric/cli.
